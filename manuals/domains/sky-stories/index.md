# SkyStories

SkyStories is the editorial system that powers the public Sky Stories pages on the WebSite. Editors create and publish stories in BackOffice; the sync workflow pushes them to Strapi (the CMS that serves the public site); the WebSite renders them with locale-aware content.

This domain covers the BackOffice authoring surface, the public reading surface, and the bridges between them (media editing, related tours, keyword taxonomy).
