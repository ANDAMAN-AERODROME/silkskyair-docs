# Releases

Release-by-release compilations that link to the feature manuals shipped in each release. A release page is a curated list — it points at the (release-agnostic) feature manuals under **Manuals by Domain**, with a short release-context line per feature.

Use these pages when onboarding to a recent release or briefing staff on what to test before a production cutover.
