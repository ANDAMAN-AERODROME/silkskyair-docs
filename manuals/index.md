# SilkSkyAir Documentation

Andaman Aerodrome platform documentation. Three ways to find what you need:

- **By domain** — feature manuals grouped by the part of the system they cover. These pages are release-agnostic and document how each feature works today.
- **By release** — release-specific compilations that link to the feature manuals shipped in a given release. Use these for staff training on a new release or for QA briefings.
- **Platform** — cross-cutting engineering reference documentation, such as the inventory of third-party systems the platform depends on.
